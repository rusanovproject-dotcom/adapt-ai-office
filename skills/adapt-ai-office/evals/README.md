# Проверки скилла

evals.json — исполняемый набор fresh-context задач с synthetic fixtures и expectations. cases.json — исходный backlog из шести спецификационных сценариев, не отчёт выполненных проверок.

Не считай модельный ответ runtime smoke. Для конкретного переносимого офиса строй новую suite из inventory и выполняй native/live gates по scope. Case local-authorized-apply проверяет фактические безопасные файловые операции в fixture, не engine compatibility.
