# Adapt AI Office

Навык для адаптации существующего AI-офиса под Codex, Claude Code или другого владельца.

**Главное — содержание MD-файлов и связи между ними:** как устроены инструкции, кто их читает, как выбирается сотрудник и где он берёт знания. Навык помогает перестроить эту логику под целевую среду, сохранив особенности конкретного офиса.

## Подход

1. Разобраться в существующих папках, MD-файлах и маршрутах.
2. Предложить минимальный список изменений: что переписать, переместить, разделить или оставить — и зачем.
3. Адаптировать тексты, ссылки и порядок чтения.
4. Проверить несколько рабочих запросов и применимые пункты чек-листа.

Нет обязательного дерева папок, состава команды или набора отчётов. Боты, хуки и серверные расписания проверяются дополнительно, если они существуют и входят в задачу.

## Установка

Скачайте репозиторий:

```bash
git clone https://github.com/rusanovproject-dotcom/adapt-ai-office.git
```

Из папки своего офиса скопируйте каталог навыка. Замените путь к скачанному репозиторию на свой. Если одноимённый навык уже установлен, сравните версии перед заменой.

Для Codex:

```bash
mkdir -p .agents/skills
cp -R /path/to/adapt-ai-office/skills/adapt-ai-office .agents/skills/
```

Для Claude Code:

```bash
mkdir -p .claude/skills
cp -R /path/to/adapt-ai-office/skills/adapt-ai-office .claude/skills/
```

Откройте новую сессию и убедитесь, что ассистент находит adapt-ai-office.

## Пример

```text
Используй adapt-ai-office. Адаптируй мой офис с Claude Code под Codex.
Сначала разберись в содержании MD-файлов, карте папок и маршрутах.
Сохрани мою методологию, память и рабочую структуру.
Предложи необходимые изменения и выполни разрешённую локальную адаптацию.
```

Навык — инструкция для ассистента, не автоматический конвертер. Он не переносит секреты и клиентские данные в публичные шаблоны. Публикация и переключение действующих сервисов выполняются только в разрешённом пользователем объёме.

Обезличенные примеры проблем — в [Issues](https://github.com/rusanovproject-dotcom/adapt-ai-office/issues); изменения — через pull request.
